# ZigZag 0.1.12

More ways to shape a design, lettering fonts ready to use offline, and
worksheets ready for the sewing room. Windows gets a signed installer.

## Shapes and stitches

- **Pathfinder:** Divide, Trim, Merge, Crop, Outline and Minus Back join
  the Shape Modes in the Transform panel and Object › Pathfinder.
  Repeat Pathfinder (⌘4) applies the last operation again. Trim and Merge
  remove stitching hidden under later objects; Outline sews each edge once.
- Groups act as one shape in the Shape Modes, results stay in their
  original group, and corners stay sharp.
- **Use as Motif** turns artwork into a pattern for textured fills or
  repeated running stitch with Motif Fill.
- **Trim Before** controls the cut before an individual object, including
  through an agent. Manual routes survive saving and reopening, and
  crossing travel stays hidden while objects are moved or transformed.

## Lettering

- Seventeen bundled fonts work offline from the first launch, including
  eleven outline families and six single-line fonts for running stitch.
- More fonts are available from the font menu and download when selected.
  Embroidery fonts are marked in the menu and select running stitch.

## Worksheets and everyday work

- **File › Print Worksheet…** (⌘P) opens a worksheet in the browser to
  print or save as PDF. Each color stop has its own picture, thread from
  the chosen chart, stitch count, trims and estimated time.
- Set sewing speed and change/trim times on the worksheet, and include an
  optional client proof page.
- **File › Open Recent** brings recently used designs back quickly.
- **Help › Contact Support…** sends a message from inside the app.

## Placing files and the command line

- A placed machine file keeps its digitized size and comes in as one
  group with the file's whole name. Renaming and copying keep group names.
- Agents can place files with `place_file`; the CLI supports
  `zigzag convert … --place FILE[@X,Y]` for PES, PEC, DST, EXP, JEF and VP3.
- Saved SVGs preserve their placement on the hoop. `zigzag info` and
  `zigzag machines` report more machine settings.

## Windows and downloads

- The Windows installer adds Start menu and file associations, supports
  `zigzag://` links, and can add the CLI to PATH without administrator rights.
  The portable zip remains available.
- The installer and all three Windows executables are signed with Azure
  Artifact Signing. The release workflow verifies their signatures and
  tests installation and removal before uploading them.
- The Mac app and DMG are signed and notarized by Apple, for Apple Silicon
  and Intel. Linux downloads are available for x86-64.

For Homebrew installations, run `brew update` followed by
`brew upgrade --cask --greedy simpsoka/zigzag/zigzag`.
