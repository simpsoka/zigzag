# ZigZag 0.1.0

The first public release of ZigZag, a visual editor for turning SVG artwork
into machine embroidery.

- Import SVG artwork or trace PNG/JPEG images into vector shapes.
- Edit fill, satin, running stitches, lettering, and stitch settings visually.
- Export PES, DST, EXP, JEF, or VP3 embroidery files.
- Send designs directly to a Brother Skitch (PP1) over Bluetooth.
- Use the bundled command-line tool and MCP bridge for agent workflows.

## Install on Mac

Download **ZigZag.dmg**, open it, and drag **ZigZag** into **Applications**.
Requires macOS 11 or later; one download supports Apple Silicon and Intel.
The app and DMG are signed and notarized by Apple.

`ZigZag-0.1.0.dmg` is the same download with the version in its filename.
`SHA256SUMS.txt` contains checksums for both filenames.
